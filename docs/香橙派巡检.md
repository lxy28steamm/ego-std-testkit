# 香橙派巡检

工作台左侧选择“香橙派巡检”，或双击“启动香橙派巡检.bat”。独立连接表单不使用顶部的Ego设备地址。

## 使用

1. 填写设备地址、SSH端口、用户名。密码只用于当前连接，不保存；也可以指定本机SSH私钥，或使用现有SSH代理/默认密钥。
2. 在“关注的服务”填最多8个服务单元，以逗号分隔。默认检查`ssh.service`；非Debian系统可改为`sshd.service`或实际服务名。
3. 按本轮验收条件设置温度、磁盘、内存、CPU告警阈值。初始值仅用于提示，不代表板卡厂商的极限标准。
4. 点击“开始香橙派巡检”。首次未知SSH主机需要核对指纹后才发送认证信息；只在当前工作台会话信任该指纹，不自动改写known_hosts。已知主机密钥改变时停止连接。
5. 查看逐项结果，点击“打开本轮报告”。需要终止时点击“停止巡检”，等待连接/探测结束后再关闭窗口。

工作台依赖已有的PySide6和Paramiko。设备需运行Linux，开启SSH，提供Python3；探测从SSH标准输入执行，不向设备复制或安装脚本，不需要sudo。

## 默认20项

| 检查 | 范围 |
|---|---|
| SSH、型号、系统内核、开机时长 | 核实连接目标及系统身份；时长不等同于稳定性验收 |
| CPU、内存、磁盘、挂载、温度 | CPU约1秒采样；内存按MemAvailable；只检查挂载标志，不写测试文件 |
| 存储、网卡地址、默认路由、时间/NTP | 当前快照，不测试外网带宽，不修改路由 |
| 失败服务、自选服务 | systemd状态；active不等于实际业务功能通过 |
| 内核日志摘要 | 本次启动最近最多50条错误级别日志的行数与类别，不保存正文；无权限时未测 |
| USB清单 | 只验证枚举读取，不表示外设正常 |
| 摄像头、串口/GPIO、GPU/NPU | 展示节点数量并记未测，不打开设备、不读写引脚、不执行计算 |

默认包含1个自选服务，共20项；增加服务会增加对应检查。缺少数据、权限、工具或驱动时记未测；阈值超限、时间不同步和失败系统服务记待确认；明确配置要求运行的服务未运行时记失败。不会因为设备节点存在就将专项测试计为通过。

## 数据和限制

结果保存在`out/orangepi/<本轮编号>/`，包括`session.json`、`metrics.json`、`cases.csv`和`summary.html`。报告可筛选、搜索、打印；“加载历史记录”选择对应session.json，只读查看。

报告绑定本轮地址、型号、系统、内核、时间和阈值。不包含SSH密码或私钥内容；整个out目录已被Git忽略，现场网络地址和设备信息不会随源码提交。

不自动重启、升级、修改配置、开关服务、写存储、切换网络、进行压力测试或占用摄像头串口。后续硬件专项需先明确板卡/外设型号、接线、业务进程占用情况和验收条件。

命令行示例（密码在终端提示处输入，不能跟在参数后面）：

```powershell
.\.venv-gui\Scripts\python.exe orangepi_inspection.py --host <设备地址> --user <用户名> --password
```

首次命令行连接会给出指纹并停止，核对后可传`--trust-fingerprint SHA256:...`。密钥登录可使用`--key-file <本机私钥路径>`。

离线验证：`.venv-gui\Scripts\python.exe -m unittest test_orangepi test_app_patrol -q`。这些测试不连接设备。
