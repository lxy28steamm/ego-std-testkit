# 香橙派：主机常规 + 外接设备专项

界面提供三个执行范围：仅主机常规、仅外接专项、两者一起。结果可以按模块筛选，报告分别统计，不再默认所有设备都是 UMI。

## 设备识别

默认读取 `/api/v2/health` 的启用配置，再核对连接和流水线状态。单槽识别 EGO、UMI 或 DEX，恰好启用 EGO Plus 和 DEX 两个槽时识别为联动。其他多槽组合不能自动开始短采集。

## 一条命令完成巡检

在仓库根目录运行以下 PowerShell 命令，把 IP 换成待检设备地址。加上 `--record` 会在设备上创建测试任务并实际录制，默认 15 秒。

```powershell
.\.venv-gui\Scripts\python.exe orangepi_inspection.py --host 192.168.24.83 --record
```

脚本自动识别设备、检查主机与外设、启动并停止短采集、下载并检查 MCAP，最后输出 JSON 摘要和 HTML 报告路径。联动模式在录制前检查当前预览流，单设备模式在录制期间检查。只想看当前状态时去掉 `--record`。要专门验证双设备联动，可追加 `--device linked`，这样现场只有单设备时会直接报告配置不符。采集时长可用 `--record-seconds 10` 至 `--record-seconds 60` 设置。

脚本遇到已有录制会跳过启动并报告原因。一次运行不会自动上传、测试实体按键或切换设备配置。请结合输出中的 `counts` 阅读结果，退出码 0 也可能包含未测或待确认项。

## 主机常规（20项）

接口、设备SN/软件版本、存储状态/挂载选择/空间、电池识别及参数、充电状态、电气标准、充放电/续航、网络/网线/Wi-Fi/扫描、云端在线与心跳、登录正反向和现场显示。只读模式只使用业务 HTTP API，不需要 SSH。缺产品标准或现场条件的项目明确未测。

## 外接设备专项（16项）

三类独立适配器共用执行生命周期，不共用连接和标定判据：

| 设备 | 连接 | 标定 | 数据契约 |
|---|---|---|---|
| EGO | USB相机/IMU，实际型号槽位和相机芯片SN | 相机/IMU标定状态，文件中标定附件及元数据载体 | 视频与IMU必须同时存在，核对各流时间戳 |
| UMI | 单/双手串口、手侧识别，每侧相机和VIVE按绑定启用 | 每手标定信息及端口匹配 | 控制/夹爪流、已配置的鱼眼/双目视频、已启用VIVE |
| DEX | 单/双手串口，逐手近手相机和遥测 | 每手URDF标定与关节映射 | 关节/触觉/IMU遥测及已配置视频，未知编码不按EGO规则判通过 |

每种专项分别记录连接、传感器、标定、预览、历史会话、数据流、频率、写入、延迟、健康、重启、本轮实采、MCAP数据结构、上传和按键。标定可读或设备报告valid不等同于物理标定精度通过。

## 实采与数据安全

勾选短采集后创建独立测试任务；默认15秒，可设10～60秒。数据按目标设备选择上传类别 ego_stereo / umi / dex，并下载校验MCAP尾部、CRC（若有）、消息数、时间戳、topic/encoding/schema及标定载体名称。文件保留，不删除历史数据。已有采集时拒绝启动；停止仅针对本轮会话，按键测试模式只处理本轮唯一测试目录产生的会话。

上传需要已授权的系统分配任务ID，只允许上传只包含本轮文件的目录，并保留本地文件。云端在线/设备报告上传完成不等于云端文件内容已独立读回。

## 验收标准和现场操作

标准JSON参考 `umi-acceptance-rules.example.json`，需按当前型号配置完整topic、标称频率、容差、电压范围、电流方向和存储延迟。不同类型的流标准不能混用。2GiB存储余量和300秒心跳仅为可调整提示阈值。长时间续航、插拔供电、网络切换、标定精度和显示需现场条件；未执行不算通过。

结果在 `out/orangepi/<本轮编号>/`，包含报告、session.json、metrics.json。历史记录只读，旧报告不会重标为新设备结果。

命令行只读示例：

```powershell
.\.venv-gui\Scripts\python.exe orangepi_inspection.py --host 192.168.110.131 --device auto --scope all
.\.venv-gui\Scripts\python.exe orangepi_inspection.py --host 192.168.110.131 --device ego --scope peripheral
.\.venv-gui\Scripts\python.exe orangepi_inspection.py --host 192.168.110.131 --scope host
```

`--device system` 保留旧SSH系统诊断兼容入口，不计作外接设备验收。登录密码仅本轮内存使用，不保存在配置或报告。MCAP校验需mcap依赖，安装依赖.bat已包含。
