# 香橙派设备 HTTP 接口文档

- 设备地址：`http://192.168.50.25:18000`；服务：`LivStudio Edge`；版本：`D-o-0.0.29`。
- 文档依据：2026-11-03 从设备 `/openapi.json` 实时获取；接口与字段以设备当前版本为准。
- 当前文档覆盖公开定义中的 **84 个路径、105 个 HTTP 操作**。不同设备类型（EGO、UMI、DEX）的接口是否可用取决于当前选择和连接情况。
- 只读请求 `/api/v2/health`、`/api/v2/storage`、`/api/v2/network`、`/api/v2/network/wifi` 曾在当前地址分别返回 HTTP 200；Wi-Fi 查询约 8 秒。其余接口没有在本次文档编写中逐项实测。
- 返回 200 表示接口响应成功，不等于设备、传感器、采集或上传验收通过。HTTP 422 在接口定义中通常表示请求参数校验失败。

## 给初学者的调用示例

在 Apifox 里新建 HTTP 请求，选择 `GET`，输入完整地址并发送：

```text
http://192.168.50.25:18000/api/v2/health
```

检查响应状态码和 JSON 中 `overall_state`、`devices`、`storage`、`session` 等字段。字段的合格标准需按产品定义判断。网络 Wi-Fi 查询建议超时至少 20 秒。

设备文档中很多接口含可选 Cookie `ego_v2_session`；是否需要登录取决于设备访问配置，不能把可选描述理解为所有部署都免认证。不要把账号密码、Cookie 或响应中的敏感信息放进共享文档。

## 使用边界

- `GET` 通常用于读取，但某些查询（例如扫描 Wi-Fi、预览或下载）可能耗时或消耗资源，不能保证毫无副作用。
- `POST`、`PUT`、`PATCH`、`DELETE` 包含采集、上传、切网、删除、标定写入和升级等操作；应先确认目标、参数和现场状态。不要对整份文档批量发送。
- `<hand>`、`{job_id}` 等占位参数需要替换成实际值。文档中的接口存在不代表当前连接的外设支持，也不证明对应硬件功能已通过测试。
- 此清单仅覆盖设备公开的 HTTP OpenAPI；不覆盖 SSH、未知 TCP/UDP 端口或未列出的 WebSocket。
