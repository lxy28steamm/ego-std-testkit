# USB 相机原始 H.264 录制工具

双击 `启动录制工具.bat`。选择相机、H.264 模式和保存位置，点击“开始录制”；结束后点击“停止并保存”，等待完成。

工具采用 DirectShow 接收 H.264 数据，不重新编码。启动时丢弃 SPS 参数集出现之前的数据；后续样本原样写入。结束后在视频旁生成 `.h264.json`，记录模式、字节数、样本数、跳过的启动样本数和 YCTC 标记数。

如果本机 PATH 中能找到 ffprobe，会自动检查文件编码和分辨率；检查结果不代表全部画面完整。YCTC 标记数量只是线索，不能证明完整 IMU 数据或没有丢帧。裸 H.264 的时长和帧率信息可能不完整，正式使用前需检查画面、实际分辨率及 IMU 数据。相机若被其他软件占用，可能无法打开；请先停止其他采集。

本机需要 Python 和工作台 `out/usbcam-build-deps` 中的 pygrabber、comtypes、numpy，当前工具依赖这些目录，不可单独复制运行。设备与格式列表每次重读，设备变化需重新选择。
